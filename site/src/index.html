How this was measured

An 85‑second test recording made for Cutalong’s own checks. A speech synthesiser read a tech review with the intro redone at the end, one line said five times, sentences broken off, a groan and a laugh. Cutalong’s transcription wrote it down with the app’s own prompt settings, /takes cut it, and the cut was scored word by word against the log of what was planted. The lines are shown as they were said. It is one recording, not an average, and real speech is messier.

Questions

Do I need an API key?

Yes, an Anthropic API key, for turning what you say into edits. Cutalong walks you through making one. Slash commands, length cuts and exports work without it.

What does it cost?

What Claude does is billed to your own Anthropic account, at Anthropic’s prices, so you pay for what you use. Cutalong’s own price: to be set by the owner.

What does Claude see?

The words of your recording and the edit, never the footage. For a vlog it also sees three small stills from each moment, unless you turn off “Let Claude see frames from my footage” in Settings.

Does it work offline?

Mostly. Cutalong needs your Anthropic key set up once. After that, and once the transcription model has downloaded, transcription, slash commands, length cuts, the editor and export run with no connection. Turning a sentence into an edit needs Claude.

Which Macs does it run on?

Macs with Apple silicon on macOS 14 Sonoma or later. The transcription and vision helpers are built for macOS 14.
